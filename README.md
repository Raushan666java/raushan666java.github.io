# Raushan - Personal Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## 🚀 Features

- Modern responsive design
- Dark theme with GitHub-inspired colors
- Smooth animations and transitions
- Mobile-friendly navigation
- Professional layout with sections for:
  - Hero/About
  - Skills
  - Experience Timeline
  - Projects Showcase
  - Education
  - Contact Information

## 📁 Project Structure

```
raushan666java.github.io/
├── index.html          # Main portfolio page
├── style.css           # Complete styling
├── images/             # Image assets folder
│   ├── profile.jpg     # Your profile photo (300x300px recommended)
│   ├── about.jpg       # About section image (400x300px recommended)
│   ├── project1.jpg    # First project screenshot (300x200px)
│   ├── project2.jpg    # Second project screenshot (300x200px)
│   └── project3.jpg    # Third project screenshot (300x200px)
└── README.md           # This file
```

## 🖼️ Images Setup

Add the following images to the `images/` folder:

1. **profile.jpg** - Your professional headshot (square format, 300x300px minimum)
2. **about.jpg** - An image representing your work or passion (landscape format, 400x300px minimum)
3. **project1.jpg, project2.jpg, project3.jpg** - Screenshots or previews of your projects (landscape format, 300x200px minimum)

## 🌐 Deployment

This site is automatically deployed via GitHub Pages. Simply push your changes to the `main` branch.

**Live Site:** https://raushan666java.github.io/

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Poppins)

## 📝 Customization

1. Update personal information in `index.html`
2. Modify colors and styles in `style.css`
3. Add your own images to the `images/` folder
4. Update project links and descriptions
