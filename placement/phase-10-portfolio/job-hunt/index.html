    Where to Apply¶

    Platform Strategy¶

    LinkedIn:
  → Profile optimized with AI keywords
  → #OpenToWork banner
  → Post 3x/week about AI engineering
  → Connect with AI startup founders
  → Apply to "Easy Apply" jobs daily

Wellfound (AngelList):
  → Best for startup roles
  → Filter: AI, remote, early-stage
  → Direct message to founders
  → Salary expectations mentioned

X/Twitter:
  → Follow AI startup founders
  → Engage with AI engineering community
  → DM for roles (not random — genuine engage first)
  → Hashtags: #Hiring #AIEngineer #Remote

Niche Boards:
  → ai-jobs.net
  → mlengineer.io
  → remoteok.com (filter: AI)
  → ycombinator.com/jobs
  → LinkedIn "AI Engineer" searches

    Cold DM Strategy¶

    Framework for DMs:

1. Warm up (3-4 days)
  → Like their posts
  → Comment with value (not "Great post!")
  → Share their content

2. DM Template

"Hi [Name],

I've been following [Company]'s work on [specific project].
Impressed by [specific detail].

I'm an AI Engineer building production RAG systems and
multi-agent architectures (Document AI, ApexERP).

Given your work on [related field], I thought we might
have interesting synergies. Would you be open to a
quick 10-min call?

Best,
Raushan
https://github.com/Raushan666java"

3. Follow up (after 5 days)
  → "Just following up on my message. No pressure if
     you're busy. Either way, keep up the great work!"

    Resume Tips¶

    Skills Section¶

    Only include skills you can defend in interview:

✅ Python (FastAPI, SQLAlchemy, asyncio)
✅ LangChain / LangGraph (RAG, agents, chains)
✅ Vector Databases (Qdrant, Chroma)
✅ LLMs (GPT-4, Claude, Llama)
✅ Docker, Docker Compose
✅ Redis, PostgreSQL
✅ Git, GitHub Actions
✅ n8n, automation pipelines
✅ System Design (AI systems)
✅ REST API Design

❌ JavaScript/TypeScript (unless strong)
❌ React/Vue (unless applying full-stack)
❌ TensorFlow/PyTorch (unless trained models)
❌ Kubernetes (unless actually used)

    Projects Section¶

    Format:
  Project Name | [Live] [GitHub] | Tech Stack

  • Built [what] using [tech] to solve [problem]
  • Achieved [metric] (e.g., 95% accuracy, 2s latency)
  • Deployed on [infrastructure] serving [n] users

Example:
  Document AI | Live | GitHub
  FastAPI | LangChain | Qdrant | GPT-4o | Docker

  • Built production RAG system for business document Q&A
    using LangChain + Qdrant with hybrid search and re-ranking
  • Achieved 95% retrieval accuracy with <2s average latency
  • Deployed on Hetzner VPS with Docker Compose, serving
    100+ indexed documents

    Experience Reframing¶

    Current: "Laravel Developer at ApexPillar Technologies"

Bad reframe:
  "Built web applications with PHP"

Good reframe:
  "Full-stack engineer building production SaaS applications
   with 3+ years of experience in API design, database scaling,
   and system architecture. Recently transitioned to AI
   Engineering — building RAG systems, multi-agent
   architectures, and automation pipelines."

Key: Show progression from backend → AI, not just current role
